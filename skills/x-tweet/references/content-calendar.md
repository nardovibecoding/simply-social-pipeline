# Content Calendar

Use this as a loose prompt, not an automation schedule.

| Day | Type | Source |
|---|---|---|
| Mon | Build note | Something public you changed |
| Tue | Lesson | A mistake or debugging lesson |
| Wed | Tool note | A tool you used and can recommend |
| Thu | Short thread | A repeatable workflow |
| Fri | Metric | A public-safe number or comparison |
| Sat | Question | A genuine open question |
| Sun | Reply day | No original post required |

Rules:

- Skip days with nothing real to say.
- Keep examples public-safe.
- Do not post raw logs, private project names, or screenshots with secrets.
