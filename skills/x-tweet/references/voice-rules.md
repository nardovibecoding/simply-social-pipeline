# Voice Rules

## Tone

Write like a practitioner sharing a useful observation.

- Specific beats impressive.
- Plain beats clever.
- Lessons beat announcements.
- Drafts should sound like something a person would say out loud.

## Formatting

- Normal capitalization.
- Short paragraphs.
- No hype words.
- No private names, local paths, credentials, screenshots, logs, or stack traces.
- No more than two hashtags.

## Draft Checklist

- [ ] One clear point.
- [ ] One concrete detail.
- [ ] No private implementation detail.
- [ ] No credentials, IDs, paths, hostnames, cookies, or logs.
- [ ] Would still make sense to a stranger.
